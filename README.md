## Introduction
이 프로젝트는 정규표현식을 사용하여 전화번호, 이메일, 이름을 추출하는 프로그램 입니다.
## Feature
-  선택한 doamain의 이메일만 추출
-  한국 전화번호만 추출
-  영어 풀네임만 추출
## Requirements
- Python3
- Streamlit
## Quick Start
1. 의존성 설치 : `pip install -r requirements.txt`
2. 게임 실행 : `streamlit run app.py`
